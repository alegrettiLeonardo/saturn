# Reference artwork refresh

The sidebar logo, turbine artwork and seven navigation icon silhouettes were cropped from the supplied approved SATURN reference images into a compact WebP atlas. Both desktop and HTML consume the atlas. No engineering data or solver equations are modified. The HTML prototype uses illustrative results and is not a solver execution. The existing project loader and candidate write-back limits remain. The ZIP's original native baseline and selected GUI/geometry tests passed locally (13 tests) after restoring Linux executable bits. The asset adapter was exercised against the supplied ZIP's Tk shell under Xvfb. The full remote bootstrap was not executed locally because GitHub DNS access is unavailable in the execution container; the PR must be qualified from a clean checkout before merge.
